# Avatar models

## Seed-san.vrm

`Seed-san.vrm` is the official VRM 1.0 sample model from the
[VRM specification repository](https://github.com/vrm-c/vrm-specification/tree/master/samples/Seed-san).
It is supplied by VirtualCast, Inc. under the [VRM Public License 1.0](https://vrm.dev/en/licenses/).

The model includes VRM 1.0 expression presets and facial morph targets, making it
useful for validating expression and lip-sync support.
